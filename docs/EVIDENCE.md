## Found and fixed while recording

- **"Book 9 days of earned leave from …"** (a chat suggestion button) was not recognised as a leave request; the leave rule only matched the exact phrase "book leave". Fixed in `policies/intents.v3.yaml` with tests.
- An approvals title showed a code exception name ("Refused · PointerOnlyViolation"), and a breaker label read "It assets". Both now read in plain words.

## Known limits (honest)

- Exit automation on Groq is 37% (81% on the simulator): the Devil's Advocate's model layer raises false alarms on a real model (9% precision). See `bench/results/groq.md` and PROGRESS.md.
- The console has no login of its own (persona switcher behind basic auth); Slack/Teams adapters are not built; workflows are edited as files, not on screen.
